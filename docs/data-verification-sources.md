# 믹스 데이터 교정 대조 기록

2026-08-20 데이터 교정 시 다음 공개 믹스법 자료를 대조했다.

- [믹스마스터 메탈 믹스법](https://mixforum.tistory.com/54): 블루메탈이 2단계 재료로 쓰이는 메탈 계열 조합 표기와 데빌메쉬 조합을 확인했다.
- [믹스마스터 짐승 믹스법](https://mixforum.tistory.com/32): 밀크카우·올드매지션·매드카우의 재료 순서 및 단계 표기를 교차 확인했다.

공개 자료의 일부 과거 표기는 현재 ABYSS 원본과 차이가 있을 수 있으므로, 실제 반영은 사용자 보고와 사이트의 최신 영구 저장 데이터 기준으로 수행했다. 재업로드 시에는 블루메탈 2단계와 매드카우 재료 순서가 유지되도록 파서 보정 규칙을 적용한다.
