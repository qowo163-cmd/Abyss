# 실제 거래소 가이드 캡처 메모

- 승인된 회원으로 로그인된 세션에서 홈 화면과 좌측 거래소 메뉴를 확인했다.
- 실제 거래소 화면은 `https://mixmasterdb-uehrnkpd.manus.space/marketplace` 경로로 접근한다.
- 홈 화면의 최신 업데이트에는 부분 수량 거래·거래 요청함·내 등록글 추가(v3.93.0)가 표시된다.
- 거래소 화면은 첫 로드 직후 비어 있는 상태가 일시적으로 나타나므로, 실제 UI가 완전히 로드된 뒤 캡처해야 한다.
- 로그인된 세션의 홈 화면에서는 거래소 메뉴와 최신 v3.93.0 업데이트를 확인했다.
- 직접 `/marketplace` 경로로 접근할 때 빈 화면이 나타나는 현상이 있어, 홈의 좌측 거래소 메뉴를 통한 화면 전환도 확인한다.
- 실제 홈 메뉴를 통해 거래소로 이동한 뒤, 판매중·구매중·교환중·아이템 거래·통합 등록·요청함·내 등록글의 상단 탭과 거래 화폐·통계·검색 영역이 표시되는 것을 확인했다.
- 캡처 시점에는 실제 등록글과 미처리 요청이 없어 판매중 화면의 빈 상태와 요청함 배지 0건 상태가 표시된다.
- 통합 등록의 판매 등록 화면은 헨치 검색, 판매 수량, 전체 자사 가격, 판매 메모, 판매글 등록과 내 판매글 목록을 한 화면에 제공한다.
- 같은 영역의 구매 등록 화면은 구매 헨치, 구매 수량, 제시 자사, 구매 메모, 구매글 등록과 받은 판매 제안·내 판매 제안을 제공한다.
- 교환 등록은 내가 줄 헨치와 원하는 헨치 목록을 입력하고 자사 가격 없이 교환글을 등록하는 구조다.
- 아이템 거래는 전체·판매·구매·교환 필터, 아이템 등록, 검색 기능을 제공하며 헨치 거래와 같은 상단 통합 탐색 구조를 사용한다.
- 요청함은 판매·구매·교환·아이템의 받은 요청을 모아 처리하며, 미처리 건수와 수락·거절·거래 완료 처리의 안내를 표시한다.
- 내 등록글은 실제 판매글의 헨치명·수량·가격·등록 상태와 등록 취소 동작을 카드 형태로 한곳에서 제공한다.
- 실제 다수 수량 판매글(비스쿠 2마리·전체 자사 2개)에서 거래 요청을 열면 요청 수량을 1~2마리 범위에서 선택할 수 있고, 마리당 자사와 요청 수량에 따른 총 자사가 자동으로 표시된다.
