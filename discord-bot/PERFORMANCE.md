# 성능 최적화 검증 기록

## 적용 사항

- 페이지와 모바일/데스크톱 앱을 지연 로딩하여 초기 경로에서 필요하지 않은 화면 코드를 분리했습니다.
- 몬스터 데이터는 공통 구독 캐시를 통해 공유하며, 활성 페이지가 있을 때만 15초 간격으로 조건부 재조회합니다.
- 몬스터 API는 ETag를 반환하며 변경이 없으면 `304 Not Modified`로 대용량 JSON 재전송을 막습니다.
- 헨치 목록은 처음 60개만 렌더링하고 추가 표시 버튼으로 DOM 크기를 제어합니다.
- 헨치·재료·믹스 트리·역산·레벨·즐겨찾기 검색에는 지연 검색 또는 메모화된 결과를 적용했습니다.
- 주요 목록·트리·홈 화면 이미지는 `loading="lazy"` 및 `decoding="async"`로 렌더링 비용을 분산했습니다.
