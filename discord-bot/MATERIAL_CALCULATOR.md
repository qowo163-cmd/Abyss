# 재료 계산기 검증 기록

재료 계산기는 선택한 헨치의 `main`, `sub`, `main2`, `sub2` 레시피를 따라 필요한 재료를 집계합니다. **`acquired: "0"`인 득코 가능 헨치는 173레벨 이하에서 가장 상위(목표에 가장 가까운) 확보 재료로 집계하고, 그 헨치의 하위 믹스는 더 펼치지 않습니다. 174레벨 이상이면 하위 믹스를 펼쳐 173레벨 이하의 재료를 찾습니다.** `acquired: "x"`인 득코 불가능 헨치는 하위 조합법이 있으면 하위 믹스를 펼칩니다. 레벨과 관계없이 하위 조합법이 없는 헨치는 목록에서 빠뜨리지 않습니다. 단, 득코 불가능하고 하위 조합법도 없는 헨치의 체크박스는 비활성화됩니다. `acquired` 값이 없는 오래된/부분 데이터에는 140~173레벨을 최종 재료로 취급하는 보완 규칙을 적용합니다. 선택한 목표 헨치 자체에 조합법이 없을 때는 목표 헨치 자체를 수량 목록에 표시합니다. 레시피 뒤의 단계 표기(예: `[5]`)는 헨치 레벨로 오인하지 않고 이름 매칭에만 사용합니다.

| 검증 항목 | 결과 |
|---|---|
| 중첩 레시피 재귀 집계 | 확인 |
| 제작 수량 배수 반영 | 확인 |
| 재료 체크 시 구한/남은 수량 갱신 | 기존 기능 유지 |
| 보조 재료 `main2`·`sub2` 포함 | 확인 |
| 득코 불가능 헨치만 하위 믹스로 확장 | 확인 |
| 첫 번째 득코 가능 헨치에서 멈춤 (그 하위 믹스는 펼치지 않음) | 확인 |
| 하위 믹스가 없는 헨치(네펠레맨 등) 표시 | 확인 |
| 복수 하위 조합 선택 | 계산 함수 시나리오 확인 |

## 복수 조합법

`main + sub`와 `main2 + sub2`는 서로 다른 대체 조합법으로 취급합니다. 재료 계산기에서 조합 1/2를 선택할 수 있으며, 득코 불가능한 하위 헨치에 복수 조합법이 있으면 그 선택을 재귀 계산에 반영합니다. 득코 가능한 하위 헨치의 조합법은 재료 체크 경계에서 멈추므로 선택 대상으로 펼치지 않습니다.
