> 브라우저 캡처는 완전 차단할 수 없으므로, 워터마크와 보호 기능은 무단 복제 억제 목적이며 운영체제 수준 캡처를 보장하지 않는다.
> 사용자 요청에 따라 사이트 표시명은 ABYSS서버 믹스사이트로 변경하되, 프로젝트 내부 식별자와 기존 도메인은 유지한다.
> 워터마크는 로그인한 승인 회원의 닉네임을 우선 사용하고, 비로그인·식별 불가 상황에서는 ABYSS서버 믹스사이트 문구만 표시한다.
> 서버 이미지 보호는 기존 /manus-storage 경로를 유지하면서 공개 이미지의 캐시를 제한하고, 보호는 URL 비공개가 아니라 무단 복제 억제 수준으로 적용한다.
> 이번 변경은 캡처 방지 훅·스타일, v3.4.0 업데이트 이력, 관리자·회원 관리 예외 처리를 보존한 상태에서 확장한다.
> 워터마크는 반복 텍스트 오버레이로 적용하며 관리자·회원관리·인증 경로에는 표시하지 않는다.
> 사이트 브랜딩은 VITE_APP_TITLE 또는 기존 localStorage 설정을 우선 확인한 뒤 ABYSS서버 믹스사이트를 기본값으로 반영한다.
> 이미지 보호는 서버 응답 헤더 조정과 이미지 표시 컴포넌트의 draggable=false를 함께 적용한다.
> 모든 구현 후 pnpm test, pnpm build, 관리자·공개 화면 브라우저 점검을 수행한다.
> 업데이트 이력은 새 버전 v3.5.0으로 저장하고 공개 업데이트 탭에 최신순으로 표시한다.
> 체크포인트 저장 전 todo.md의 새 작업 항목이 모두 완료인지 확인한다.
> 사용자가 직접 요청한 기능 범위 외에는 데이터 구조와 회원 인증 흐름을 변경하지 않는다.
> 공개 화면은 사용자 닉네임 노출에 동의한 것으로 간주하지 않고, 워터마크는 안내 문구를 포함한 식별용 표시로 최소화한다.
> 브라우저·운영체제의 스크린샷 자체를 완전히 차단할 수 없다는 한계를 최종 결과에 명시한다.
