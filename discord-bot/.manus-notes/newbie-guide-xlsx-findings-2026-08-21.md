# 게임 가이드 엑셀 검토 메모

작성일: 2026-08-21
원본 파일: `/home/ubuntu/upload/게임_가이드_네비게이션(2).xlsx`

## 확인된 핵심 구조

- 메인 네비게이션 시트가 있고, 실제 뉴비가이드의 큰 묶음은 `뉴비 가이드` 시트에 정리되어 있음.
- 뉴비 가이드 상위 항목은 대략 다음 흐름으로 구성됨.
  - 조작방법
  - 스킬
  - 믹스가이드
  - 장비_시너지
  - 플레이팁&재화수급방법
  - 시너지 얻는 곳
  - 축시 얻는 방법
  - 자동사냥 사용법
  - 축용_축티 가이드
  - 인첸트 1~7단계
  - 인첸트 교환 가이드
- 별도 시트로 `믹스사이트&회원가입`, `레벨존 가이드`, `사냥터 위치`, `NPC 정리`, `서버 이용가능 컨텐츠`도 존재함.

## 시트별 메모

- `시트1`: 전체 가이드 허브 역할.
- `뉴비 가이드`: 뉴비가이드 탭의 목차로 사용하기 적합.
- `믹스사이트&회원가입`: 회원가입 바로가기, 회원가입 방법, 믹스사이트 바로가기 묶음.
- `레벨존 가이드`: 별도 시트 있으나 현재 추출 텍스트는 제목 위주.
- `사냥터 위치`: 행 수가 많아 실제 세부 사냥터 데이터가 들어있을 가능성이 높음.
- `NPC 정리`: 최소 1개 이상 NPC 항목 존재 (`마지리타(어비스 서버 대표 마을)`).
- `서버 이용가능 컨텐츠`: 최소 `보스 콘텐츠`, `공성전` 항목 확인.
- `자동사냥 가이드`: `꼭!!! 필독해주세요 !!!` 강조 문구 확인.
- `인첸트 3~7단계`: 각 단계마다 드래곤/악마/짐승/새/곤충/식물/미스터리/메탈 계열 인첸트 아이템 분류가 존재.

## 구현 시 반영 방향

- 뉴비가이드 탭은 단순 텍스트 나열보다 `카테고리형 가이드 허브 + 세부 섹션 카드` 구조가 적합함.
- 엑셀의 하이퍼링크 네비게이션은 웹에서는 탭/섹션 카드/아코디언으로 재구성하는 것이 좋음.
- 추출 텍스트만으로 부족한 시트(`사냥터 위치`, `레벨존 가이드`, `인첸트 상세`)는 추가 구조 확인이 필요함.
