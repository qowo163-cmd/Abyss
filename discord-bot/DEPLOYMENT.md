# MixMaster DB 배포 안내

현재 프로젝트는 `pnpm check`, `pnpm test`, `pnpm build`와 프로덕션 번들 서버 스모크 테스트까지 완료된 상태입니다. 실제 공개 배포는 이 작업 환경에서 자동으로 실행하지 않으며, 프로젝트 관리 화면의 최신 체크포인트에서 **Publish** 버튼을 눌러 진행합니다.

배포 전에는 관리자 엑셀 업로드가 서버 API에 저장되는지, 이미지가 `/manus-storage/` URL로 접근되는지, 공개 헨치 목록에서 변경된 X항체와 이미지가 보이는지를 확인합니다. 배포 후에는 공개 도메인의 `/hench`, `/reverse`, `/material`, `/admin` 경로를 새로고침하여 최신 서버 데이터를 확인합니다.

관리자 화면에서 CSV를 업로드하면 `/api/monsters`에 데이터가 저장되고, 공개 페이지는 최대 5초 간격으로 최신 데이터를 다시 조회합니다. 이미지 선택은 `/api/monster-image`를 통해 내장 파일 저장소에 업로드되며, 몬스터 저장을 완료해야 해당 이미지 URL이 몬스터 데이터에 반영됩니다.
