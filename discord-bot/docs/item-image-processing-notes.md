# 아이템 이미지 숫자 제거 기준

2026-08-20 사용자 제공 `아이템.zip`을 확인했다. 모든 원본은 게임 아이템 아이콘이며, 아이콘의 오른쪽 아래에 수량·번호처럼 보이는 숫자 오버레이가 표시되어 있다.

- `1억GP.png`: 32×32 아이콘 오른쪽 아래의 `28` 오버레이를 제거한다.
- `40배세트.png`: 가로형 3개 아이콘 각각 오른쪽 아래의 `68`, `186`, `15` 오버레이를 제거한다.
- `곤충3차.png`: 31×32 아이콘 오른쪽 아래의 `220` 오버레이를 제거한다.
- `드래곤3차.png`: 29×31 아이콘 오른쪽 아래의 `448` 오버레이를 제거한다.

나머지 파일도 동일 원칙으로 처리한다. 아이콘 본체, 배경, 테두리, 투명도와 원래 색상은 보존하며 숫자 오버레이 영역만 자연스럽게 복원한다.

첫 AI 편집은 원본 해상도·아이콘 비율을 보존하지 못해 채택하지 않는다. 원본 픽셀 크기를 그대로 유지하는 수량 오버레이 제거 방식으로 전환한다.

픽셀 기반 1차 처리 후 가로형 `40배세트.png`의 세 숫자 오버레이가 제거된 것을 확인했다. `1억GP.png`는 아이콘 하단 우측에 숫자 형태로 보일 수 있는 잔상이 남아, 등록 전 해당 영역을 한 번 더 보정한다.

확대 원본을 재확인한 결과, 자동사냥박스의 `76`과 곤충3차의 `220`처럼 숫자 자체가 아이콘 하단 우측의 넓은 영역을 덮고 있다. 기존 밝은 픽셀만 감지하는 방식으로는 숫자 전체를 안정적으로 제거할 수 없다. 따라서 재처리는 **숫자가 표시된 하단 우측 영역 전체를 게임 UI의 어두운 배경색으로 정리**해, 숫자가 남지 않도록 한다. 이 방식은 아이콘 일부의 가려진 원본 픽셀은 복원할 수 없지만, 숫자를 완전히 숨기고 아이콘의 주된 실루엣을 유지한다.

재처리본은 숫자는 제거했지만 자동사냥박스와 속성권에서 어두운 정리 영역이 과도하게 커 아이콘 가독성을 떨어뜨렸다. 이 버전은 배포하지 않고, 숫자 영역만 자연스럽게 복원하는 이미지 편집 결과로 교체한다.
