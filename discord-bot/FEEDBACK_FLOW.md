# 공유 건의사항 처리 흐름

모든 사용자의 건의사항은 브라우저별 `localStorage`가 아니라 서버의 공용 저장소에 기록됩니다. 공개 건의사항 화면은 `/api/feedbacks`로 제출하고, 관리자 페이지는 같은 서버 저장소를 조회합니다. 서버는 새 제출과 상태 변경을 실시간 이벤트로 방송하므로, 관리자는 새로고침 없이 새 건의사항과 상태 변경을 확인할 수 있습니다.

| 검증 항목 | 결과 |
|---|---|
| 공개 건의사항 입력·전송 화면 로드 | 정상 |
| 관리자 로그인·건의사항 관리 진입 경로 로드 | 정상 |
| 서버 제출·관리자 표시·상태 변경 UI 테스트 | 통과 |
